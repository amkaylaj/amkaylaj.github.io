Project

Wearable Pulse Oximeter and Heart Rate Monitor

Spring 2026 · Circuit Design, Arduino, Sensor Fusion, CAD Design

Circuit Design Arduino Sensor Fusion CAD Design

Problem Standard pulse oximeters, which measure blood oxygen saturation (SpO2) and heart rate through photoplethysmography (PPG), are known to have reduced accuracy in patients with darker skin tones, which is a documented bias that can mask hypoxemia and lead to delayed or missed clinical intervention. My teammate and I set out to design a wearable device that begins to address this gap at the hardware level.

Approach As a two-person team, we designed and built a wearable SpO2 and heart rate monitor using a MAX30102 sensor and an ESP32 microcontroller. My focus was on the circuit schematics, PCB layout, and physical build, which included hands-on soldering, perf-board assembly, and a 3D-printed enclosure for wearability. To address the skin-tone accuracy gap, I implemented adaptive LED current control to adjust signal intensity across varying skin pigmentation, along with motion artifact detection to reduce signal noise from patient movement. Support for this project came from UVA's Venture Forward Program, which supports entrepreneurial development within the School of Engineering.

Outcome & Next Steps The result is a functional wearable prototype that demonstrates an end-to-end hardware design process, from circuit schematic to working device, with early-stage features aimed at more equitable signal accuracy. This project is still a work in progress. Next steps include formal testing across a range of skin tones to validate and refine the adaptive LED approach, along with further calibration of motion artifact detection.
